# SSRN submission version

Version v0.2.5 contains the final 26-page manuscript with seven figures and 21 references. This is a synthetic scalar mechanism study and has not undergone external peer review. The version is prepared for SSRN submission; GitHub availability does not establish SSRN acceptance.

Compared with v0.2.4, this version adds the effective-objective interpretation, an analytic quota noise benchmark, and an explanation of the high-sensitivity saturation limit. It clarifies the relation to prior mean-shift work, tightens the clinical contextual discussion, and accurately describes material AI assistance. The seven-author order and five joint first authors are retained, with only Li Shen and Junbo Ge designated as corresponding authors.

All original and exploratory numeric trajectory data are unchanged. Reproduction instructions and frozen execution materials remain in [v2](../v2/README.md), [the original study](../study/PROTOCOL.md), and [the extension protocol](../v2/extension/PROTOCOL.md). The new analytic checks are in [reviews](reviews). These are internal checks, not external peer review.

The full current paper is available as [PDF](manuscript/Feedback_selection_SSRN.pdf), [Word](manuscript/Feedback_selection_SSRN.docx), and [readable text](manuscript.md). No additional reuse license is granted by this release.
